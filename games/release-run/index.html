Alkami Release Preview · Fall 2026

Release Run

Five quick worlds. Hit the question blocks to learn each platform update, then clear the action gate in each world. Learn what changed, and what you need to do about it.

Based on the Alkami Release Preview, Fall 2026 (September 2026). Roadmap and beta items are subject to change. This is an unofficial learning game.

How to Play

  • Move: A / D or Left / Right (touch: Left and Right).
  • Jump: Space, W, or Up (touch: Jump). Stomp Glitch bugs from above. Bounce on spring pads.
  • Question blocks (gold ?): hit one from below to reveal a feature card. Each card shows what the feature does and its tag.
  • Action gate: each world ends with a question at the gate. Bump the answer block you think is right, or press 1, 2, or 3.
  • Wing badge: pick it up for one extra jump in mid-air.
  • Pause: Esc. The Release Log has every feature you have found.

The tags matter. AUTO-ENABLED means it's on. ADMIN CONFIGURATION and CONFIGURATION ENABLED mean someone sets it up. Add-On means it's a purchase. Beta means early access, subject to change.

Falling or touching a Glitch sends you back to the last checkpoint. Nothing you have learned is lost.
